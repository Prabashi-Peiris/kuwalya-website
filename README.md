
# Kuwalya Website

## Project Overview

This repository documents my contribution to the development and design of the Kuwalya fashion brand website.

Kuwalya is a Sri Lankan fashion brand focused on bespoke fashion, bridal wear, traditional designs, and contemporary collections.

My involvement in this project included:

- Website content management
- Updating website information
